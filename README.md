# Cornerstone Real Estate & Property Listing Portal

A premium, modern, fully responsive Real Estate Agency website with an integrated property listing portal and dedicated Buyer and Seller Dashboards.

Built with **HTML5, CSS3, and Vanilla JavaScript ES6** (zero external frameworks or component libraries).

---

## 🌟 Features

- **20 Complete Web Pages**:
  - `index.html` — Home 1: General Real Estate
  - `pages/home2.html` — Home 2: Featured Properties & Categories
  - `pages/about.html` — About Us: Agency & Team
  - `pages/buy.html` — Buy: Property Search & Interactive Filter System
  - `pages/property-details.html` — Property Details with Gallery, Lightbox & Enquiry
  - `pages/blog.html` — Real Estate News & Guides
  - `pages/blog-details.html` — Individual Editorial Guide
  - `pages/sell-rent.html` — Property Listing Submission & Owner Services
  - `pages/pricing.html` — Agency Services & Listing Packages
  - `pages/contact.html` — Contact: Enquiry Form, Office Details & FAQs
  - `pages/login.html` — Role-based (Buyer & Seller) Authentication Portal
  - `pages/buyer-dashboard.html` — Dedicated Buyer Discovery & Purchase Management Portal
  - `pages/seller-dashboard.html` — Dedicated Seller Listing & Sales Management Portal
  - `pages/user-dashboard.html` — User Profile Dashboard
  - `pages/admin-dashboard.html` — Administrator Dashboard
  - `pages/sitemap.html` — Complete Site Index
  - `pages/terms.html` — Terms of Service
  - `pages/privacy.html` — Privacy Policy
  - `pages/maintenance.html` — Scheduled Maintenance Page with Vector Art & Live Timer
  - `pages/404.html` — Architectural Blueprint 404 Error Page

- **Dedicated Portals**:
  - **Buyer Dashboard**: Saved properties, 3-property comparison, site visit scheduler, enquiry history, offer management with counteroffer workflows, notifications, and profile settings.
  - **Seller Dashboard**: Multi-step property submission wizard, listing status controls (Published, Under Review, Draft, Sold, Rented, Archived), lead enquiry review, site visit management, received offer evaluation, listing performance charts, and document management.

- **Global Controls**:
  - Working **Dark Mode / Light Mode** toggle (persisted in `localStorage`).
  - Working **RTL / LTR Direction** toggle (persisted in `localStorage`).
  - Interactive property search with multi-parameter filtering, price sorting, and active filter chips.
  - Interactive location exploration with map pin cards.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via any static file server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
